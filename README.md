# BLVCK-OAK-V2

A clean second-generation BLVCK OAK front end focused on easier navigation, clearer customer journeys and richer motion.

## Primary navigation

- Home
- Websites
- Services
- Portfolio
- Get started
- More / client & partner tools

## Current V2 pages

- `index.html` — redesigned home page and navigation hub
- `websites.html` — website marketplace and industry filters
- `services.html` — simplified service catalogue
- `portfolio.html` — concept-first portfolio view
- `start.html` — clear quote/contact entry point
- `tools.html` — client, payment, project, referral and partner links
- `styles.css` — shared responsive design and motion system
- `app.js` — mobile navigation, scroll progress, reveals, cursor lighting, filters and 3D card tilt
- `netlify.toml` — static Netlify deployment and security headers

The operational quote, contact, partner, referral, payment and project-progress systems currently link to the existing production BLVCK OAK site so they remain usable while their backend code is migrated into V2.

## VS Code

Clone the repository, then open `BLVCK-OAK-V2.code-workspace`. The included `.vscode/settings.json` is configured for a simple Live Server workflow.

## Deployment

The repository is ready for a separate Netlify site. Publish directory: repository root (`.`).
